# PairBook Excel 导入导出指南

## 1. 功能说明

PairBook 可以在浏览器中直接读取和生成 `.xlsx` 文件。Excel 数据不会上传到服务器。导入、导出和模板下载入口位于“我的联系人”区域中的“Excel 数据交换”。

## 2. 导出联系人

1. 点击“导出 Excel”。
2. 浏览器下载名为 `pairbook-contacts-YYYY-MM-DD.xlsx` 的文件。
3. 每位联系人占一行；所有联系方式按原有顺序展开，不会合并到单个单元格。

空通讯录也可以导出，文件中只包含固定表头。建议在批量导入前先导出备份。

## 3. 下载并填写模板

点击“下载模板”获得 `pairbook-import-template.xlsx`。模板包含 `Contacts` 数据表和“填写说明”工作表。

固定列必须保持以下名称与顺序：

```text
id, name, company, note, favorite, createdAt, updatedAt
```

- `name` 必填。
- `favorite` 只允许 `true` 或 `false`；留空按 `false` 处理。
- `id` 留空时由 PairBook 生成。
- `createdAt`、`updatedAt` 留空时使用导入时间；填写时必须是有效的 ISO 8601 时间。
- 中文、特殊字符和多行备注可以直接填写。

联系方式使用连续编号的完整四列组：

```text
method_1_id, method_1_type, method_1_label, method_1_value
method_2_id, method_2_type, method_2_label, method_2_value
...
```

- `type` 只允许 `phone`、`email`、`social`、`address`、`other`。
- 整组留空时忽略该组。
- 填写某组时，`type`、`label` 和 `value` 必须完整；`id` 可以留空并自动生成。
- 需要更多联系方式时，按相同规则向右添加完整列组，编号必须从 1 连续递增。
- 不要重命名、重排或删除固定列，也不要在数据单元格中使用公式。

## 4. 导入与确认

1. 点击“导入 Excel”并选择 `.xlsx` 文件。
2. PairBook 在本地解析全部数据，显示数据行、有效记录、错误和 ID 冲突数量。
3. 如果存在错误，预览会标明行号、字段和原因；修正文件后重新选择。含错误的文件不能应用。
4. 如果文件中的 ID 已存在于当前通讯录，选择一种处理策略：
   - “跳过冲突项”：默认策略，保留当前联系人，不导入相同 ID 的记录。
   - “替换现有联系人”：仅替换预览中明确列出的相同 ID 联系人。
5. 点击“确认导入”后，全部变更一次性写入本地存储。取消预览不会修改数据；存储失败时也不会更新当前联系人列表。

文件内部出现重复 ID 属于阻塞错误，必须先修正，不会自动覆盖或静默跳过。

## 5. 安全限制与排错

- 文件必须为 `.xlsx`，最大 5 MB。
- 一次最多处理 5000 个联系人、每位联系人最多 50 条联系方式。
- 公式、超链接等复杂单元格内容不作为联系人文本读取。
- 最多展示 500 条详细错误；达到上限时停止继续解析，修正已报告问题后重新导入。
- 浏览器隐私设置、存储空间不足或禁用 localStorage 会导致应用变更失败，并显示错误提示。
- 如果导入文件来自 PairBook 导出，文件无需修改即可重新导入；相同 ID 会进入冲突确认流程。
